# Artifact Inventory & Description

This directory contains all binary models, serialized metrics, evaluation tables, visualizations, and inference samples produced by the ResumeXpert model training and demonstration pipeline.

---

## Artifact Catalog

| File Name | File Type | Approximate Size | Generated By | Description & Faculty Presentation Purpose |
|---|---|:---:|---|---|
| [`career_classifier.joblib`](file:///artifacts/career_classifier.joblib) | Binary (Joblib) | ~144 KB | `train_model.py` | Serialized scikit-learn `Pipeline` containing the fitted `TfidfVectorizer` and trained `LogisticRegression` model. Used by all prediction scripts. |
| [`metrics.json`](file:///artifacts/metrics.json) | JSON | ~800 B | `train_model.py` | Structured machine-readable summary of training parameters, sample counts, vocabulary size, and final evaluation metrics (accuracy, macro/weighted precision, recall, F1). |
| [`classification_report.txt`](file:///artifacts/classification_report.txt) | Plain Text | ~800 B | `train_model.py` | Formatted ASCII classification report showing precision, recall, and F1-score for each of the 8 career classes. |
| [`classification_report.csv`](file:///artifacts/classification_report.csv) | Tabular CSV | ~1.1 KB | `train_model.py` | Machine-readable table containing per-class precision, recall, f1-score, and support values for tabular reporting and presentation slides. |
| [`confusion_matrix.csv`](file:///artifacts/confusion_matrix.csv) | Tabular CSV | ~500 B | `train_model.py` | The raw $8 \times 8$ confusion matrix representing true vs. predicted counts across all 320 test samples. |
| [`confusion_matrix.png`](file:///artifacts/confusion_matrix.png) | Image (PNG) | ~140 KB | `train_model.py` | High-resolution graphical heatmap of the confusion matrix with numerical cell annotations, colorbar, and labeled axes. Ideal for viva presentation slides. |
| [`class_distribution.png`](file:///artifacts/class_distribution.png) | Image (PNG) | ~80 KB | `train_model.py` | Horizontal bar chart illustrating the sample distribution and class balance across all 8 career categories (200 samples / 12.5% each). |
| [`top_terms_by_career.csv`](file:///artifacts/top_terms_by_career.csv) | Tabular CSV | ~6 KB | `train_model.py` | The top 15 highest-weighted positive TF-IDF features and their learned linear regression coefficients for each career class. |
| [`sample_predictions.csv`](file:///artifacts/sample_predictions.csv) | Tabular CSV | ~1.8 KB | `sample_predictions.py` | Results of held-out demonstration predictions on 10 realistic resume samples across all 8 classes, showing sample ID, input snippet, predicted class, probability, and correctness. |
| [`TRAINING_SUMMARY.md`](file:///artifacts/TRAINING_SUMMARY.md) | Markdown | ~600 B | Repository | High-level quick reference note summarizing dataset size, task, and train/test parameters. |

---

## How Artifacts are Used in Demonstrations

- **To show the model in action:** Run `python demo_predict.py` (which loads `career_classifier.joblib`).
- **To show statistical proof of performance:** Display `confusion_matrix.png` and `classification_report.txt`.
- **To show dataset balance:** Display `class_distribution.png`.
- **To explain feature importance:** Open `top_terms_by_career.csv`.
- **To prove generalization on held-out samples:** Open `sample_predictions.csv`.
